- css/style.css

How to run:
1. Open index.html in your browser.
2. Internet connection is needed for Bootstrap, Bootstrap Icons and Google Fonts CDN.
3. Replace the placeholder email, phone number and social profile links.
4. Replace the sample project cards with your real projects.

- Bootstrap 5
- Bootstrap Icons
- Vanilla JavaScript
- Responsive design
